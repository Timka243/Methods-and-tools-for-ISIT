# DFD (Data Flow Diagram)

## Контекстная диаграмма
<img width="3204" height="448" alt="image" src="https://github.com/user-attachments/assets/504610d9-fbf0-459d-b0d3-b6d81e0fabda" />


Контекстная DFD показывает взаимодействие пользователя с системой учёта визитов и обмен данными с БД PostgreSQL.
Пользователь отправляет запросы на просмотр/добавление/редактирование/удаление, система возвращает страницы и результаты.
Все данные локаций и визитов сохраняются и читаются из базы данных.

## Level-1 (детализация процессов)
<img width="3128" height="1376" alt="image" src="https://github.com/user-attachments/assets/f189f90e-5bb1-4344-8940-616cbfc8ab7b" />


На уровне 1 система разбивается на процессы: просмотр локаций, управление визитами и расчёт аналитики.
Процесс управления визитами выполняет запись/обновление/удаление данных в таблице visits.
Процесс аналитики получает агрегированные значения по visits для выбранной локации.
