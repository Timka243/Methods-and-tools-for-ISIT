### Диаграмма A-0 (контекстная)
Контекстная диаграмма IDEF0 описывает систему «Учёт визитов по локациям» как единый функциональный блок. На вход поступают данные визита (дата, материал/услуга, затраты, скидка), выбранная локация и теги. Управляющими воздействиями выступают правила доступа по ролям (user/admin), ограничения и структура базы данных, а также регламент работы с данными. Результатом работы системы являются сформированные списки визитов по локации, показатели аналитики и данные по пользователям (в административной части). Механизмами реализации являются веб-приложение на Flask, СУБД PostgreSQL, запуск через Docker Compose и действия пользователей системы.

### Диаграмма A0 (декомпозиция)
Диаграмма A0 раскрывает верхний уровень системы и выделяет ключевые функции:
A1 — авторизация и предоставление доступа к системе;  
A2 — управление визитами (просмотр, добавление, редактирование, удаление) в разрезе выбранной локации;  
A3 — тегирование визитов и формирование связей визит↔теги через таблицу `visit_tags`;  
A4 — расчёт аналитических показателей по локации (количество визитов, суммы, средние значения);  
A5 — административное управление пользователями (добавление и удаление), доступное только роли admin.  

Все функции выполняются под общим контролем правил доступа и ограничений целостности БД, а также реализуются средствами Flask и PostgreSQL в контейнерной среде Docker Compose.
