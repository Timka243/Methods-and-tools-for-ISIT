# ER-диаграмма
<img width="828" height="1296" alt="image" src="https://github.com/user-attachments/assets/bc5426f8-9614-4b68-a004-71c999ea4dbb" />

ER-диаграмма отражает структуру базы данных PostgreSQL.
Сущность `locations` хранит список локаций.
Сущность `visits` хранит визиты и содержит внешний ключ `location_id`, связывающий визит с конкретной локацией.
Связь: одна локация — много визитов (1:N).
