# BPMN (модель бизнес-процесса)
<img width="1848" height="2916" alt="image" src="https://github.com/user-attachments/assets/162b0c13-e068-4576-b959-4efdee5fd20f" />

Диаграмма описывает типовой процесс работы пользователя: выбор локации, просмотр данных и при необходимости добавление визита.
После сохранения визита система валидирует поля, записывает данные в PostgreSQL и возвращает обновлённые страницы (визиты и аналитика).
