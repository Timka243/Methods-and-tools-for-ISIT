# BPMN (модель бизнес-процесса)
<img width="1968" height="3924" alt="image" src="https://github.com/user-attachments/assets/34555f2c-183e-4474-9d8e-56abded59ee7" />
Диаграмма BPMN отражает основной пользовательский сценарий работы в системе и разделяет действия по дорожкам: Пользователь выполняет операции в интерфейсе, а Система обрабатывает запросы и взаимодействует с базой данных. Процесс начинается с открытия страницы входа и ввода учётных данных, после чего система выполняет проверку пользователя. При успешной проверке создаётся сессия, при ошибке входа система выводит сообщение и процесс завершается.

Далее пользователь открывает главную страницу, выбирает локацию и выполняет добавление или изменение визита. Система проверяет корректность введённых данных и сохраняет визит, фиксируя автора действия через поле created_by, после чего обновляет список визитов. Затем пользователь переходит в раздел статистики, а система рассчитывает сводные показатели на основе данных визитов и отображает результат. Завершается процесс выходом из системы и завершением сессии.
