# Ментальная карта
<img width="580" height="954" alt="image" src="https://github.com/user-attachments/assets/0846ad3f-d49b-4ca4-8310-528a7f82043f" />

Ментальная карта показывает структуру проекта и связи между основными модулями системы.  
Ветка **«Локации»** описывает навигацию по локациям и переход к аналитике/визитам.  
Ветка **«Визиты»** отражает полный цикл работы с данными визитов (просмотр, добавление с полями дата/материал/сумма/скидка, редактирование и удаление).  
Ветка **«Аналитика»** перечисляет показатели, которые рассчитываются по выбранной локации.  
Ветки **«База данных»** и **«Запуск»** фиксируют техническую основу проекта: PostgreSQL (таблицы locations/visits) и Docker Compose (сервисы app+db и init SQL).
