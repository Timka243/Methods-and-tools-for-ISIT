# Подробное описание проекта

## Назначение
Система предназначена для учёта визитов по локациям, управления данными через веб-интерфейс и получения базовой аналитики (суммы, скидки, средние значения) по выбранной локации.

## Роли
- **Пользователь/оператор**: выполняет вход в систему, просматривает локации, добавляет визиты, редактирует и удаляет записи, просматривает визиты и аналитику.
- **Администратор**: дополнительно управляет пользователями (добавление и удаление пользователей). Доступ к разделу пользователей есть только у администратора.

## Сущности
- **locations** — локации (места/точки учёта).
- **visits** — визиты: дата, материал/услуга, сумма затрат (`spent`), скидка (`discount`), привязка к локации.
- **users** — пользователи системы (логин, пароль в виде хэша, роль).
- **visit_tags** — связь визитов и тегов (многие-ко-многим).
- **tags** — справочник тегов для классификации визитов.

## Основные функции
- вход/выход пользователя;
- просмотр списка локаций;
- просмотр визитов по выбранной локации;
- добавление визита (дата, материал/услуга, сумма, скидка) с возможностью указания тегов;
- редактирование визита;
- удаление визита;
- аналитика по выбранной локации (количество визитов, сумма затрат, сумма скидок, средние значения);
- администрирование пользователей (только для администратора): добавление и удаление.

## Технологии и запуск
- **Flask (Python)** — веб-приложение
- **PostgreSQL** — хранение данных
- **Docker Compose** — развёртывание проекта
