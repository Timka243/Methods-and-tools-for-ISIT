# Подробное описание проекта

## Назначение
Система предназначена для учёта визитов по локациям и анализа показателей (сумма, скидка, средние значения).

## Роли
- Пользователь/оператор: добавляет визиты, редактирует/удаляет записи, просматривает визиты и аналитику.

## Сущности
- **locations** — локации (места/точки).
- **visits** — визиты: дата, материал, сумма (spent), скидка (discount), привязка к локации.

## Основные функции
- просмотр списка локаций;
- аналитика по выбранной локации (количество, суммы, средние);
- просмотр визитов по локации;
- добавление визита (с подсказками по уже существующим материалам);
- редактирование визита;
- удаление визита.

## Технологии и запуск
- Flask (Python)
- PostgreSQL
- Docker Compose (`docker compose up -d --build`)
