# Система учёта визитов (Visit Tracking System)

## 1. Краткое описание проекта

### 1.1. Ф.И.О. разработчиков
Валетов Тимур Маратович

### 1.2. Группа
Учебная группа: **ДЭ-306**.  

### 1.3. Тема проекта
**Система учёта визитов по локациям с ролевым доступом, тегированием и хранением данных в PostgreSQL через веб-интерфейс.**  
Проект предназначен для фиксации визитов (дата, материал/услуга, сумма, скидка), назначения тегов визитам и управления пользователями администратором, а также получения базовой аналитики по выбранной локации.

### 1.4. Цель проекта
Цель проекта — разработать простое веб-приложение для учёта визитов, которое централизованно хранит данные в PostgreSQL, предоставляет удобный интерфейс управления визитами и позволяет получать оперативную аналитику. Дополнительная цель — реализовать ролевой доступ (вход в систему, административное управление пользователями), а также обеспечить воспроизводимый запуск на любом компьютере с помощью Docker Compose без ручной настройки окружения.

### 1.5. Задачи проекта
В рамках проекта решаются следующие задачи:
- спроектировать структуру базы данных (таблицы `locations`, `visits`, `users`, а также `tags` и таблицу связи `visit_tags`), определить связи и ограничения целостности;
- реализовать создание и первичное заполнение БД через SQL-скрипты и/или автоматическую инициализацию структуры при запуске приложения;
- разработать веб-интерфейс для просмотра списка локаций и навигации между разделами;
- реализовать аутентификацию пользователей (вход/выход) и хранение контекста пользователя в сессии;
- реализовать административный раздел управления пользователями: добавление и удаление пользователей, доступный только администратору;
- реализовать просмотр списка визитов по выбранной локации;
- реализовать добавление нового визита с сохранением в БД (дата, материал, сумма, скидка) и возможностью указания тегов;
- реализовать редактирование и удаление визитов (CRUD) с корректным пересчётом данных;
- реализовать работу с тегами: выбор существующих тегов и привязка к визитам через таблицу `visit_tags`;
- реализовать расчёт аналитических показателей по локации (количество визитов, суммы, средние значения), чтобы данные пересчитывались сразу после изменений;
- контейнеризировать приложение и БД (Docker Compose) и настроить корректный порядок запуска сервисов;
- подготовить комплект документации в Markdown и набор диаграмм (Mindmap, IDEF0, DFD, BPMN, UML, ER) для описания структуры системы, ролей пользователей и потоков данных.

### 1.6. Аннотация
Проект представляет собой веб-приложение «Учёт визитов», разработанное на Python (Flask) с использованием базы данных PostgreSQL. Система предназначена для хранения визитов, привязанных к локациям, и предоставляет функции просмотра локаций, управления визитами (добавление, редактирование, удаление), назначения тегов визитам и получения аналитики по выбранной локации. Для работы предусмотрен вход в систему; административные функции управления пользователями (добавление и удаление) доступны только пользователю с ролью администратора. Развёртывание выполнено через Docker Compose: приложение и СУБД запускаются в отдельных контейнерах, а структура базы данных формируется при инициализации. Документация оформлена в формате Markdown и дополнена диаграммами, описывающими функциональную модель, потоки данных и структуру базы данных.


## Запуск
```bash
docker compose up -d --build
```
