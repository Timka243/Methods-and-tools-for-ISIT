# Система учёта визитов (Visit Tracking System)

## 1. Краткое описание проекта

### 1.1. Ф.И.О. разработчиков
Валетов Тимур Маратович

### 1.2. Группа
Учебная группа: **ДЭ-306**.  

### 1.3. Тема проекта
**Система учёта визитов по локациям с хранением в PostgreSQL и веб-интерфейсом управления.**  
Проект ориентирован на фиксацию визитов (дата, материал/услуга, сумма, скидка) и получение базовой аналитики по выбранной локации.

### 1.4. Цель проекта
Цель проекта — разработать понятное и простое веб-приложение для учёта визитов, которое позволяет централизованно хранить данные в PostgreSQL, управлять ими через интерфейс и получать оперативную аналитику. Дополнительная цель — обеспечить воспроизводимый запуск на любом компьютере с помощью Docker Compose, чтобы систему можно было быстро развернуть без ручной настройки окружения.

### 1.5. Задачи проекта
В рамках проекта решаются следующие задачи:
- спроектировать структуру базы данных (таблицы `locations` и `visits`, связи и ограничения целостности);
- реализовать создание и первичное заполнение БД через SQL-скрипты;
- разработать веб-интерфейс для просмотра списка локаций и навигации между разделами;
- реализовать просмотр списка визитов по выбранной локации;
- реализовать добавление нового визита с сохранением в БД (дата, материал, сумма, скидка) и подсказками по уже существующим материалам;
- реализовать редактирование и удаление визитов (CRUD);
- реализовать расчёт аналитических показателей по локации (количество визитов, суммы, средний чек, средняя скидка), чтобы данные пересчитывались сразу после изменений;
- контейнеризировать приложение и БД (Docker Compose), настроить корректный порядок запуска сервисов;
- подготовить комплект документации в Markdown и набор диаграмм (Mindmap, IDEF0, DFD, BPMN, UML, ER) для описания структуры системы и потоков данных.

### 1.6. Аннотация
Проект представляет собой веб-приложение «Учёт визитов», разработанное на Python (Flask) с использованием базы данных PostgreSQL. Система предназначена для хранения визитов, привязанных к локациям, и предоставляет пользователю функции просмотра локаций, просмотра и управления визитами (добавление, редактирование, удаление), а также получения аналитики по выбранной локации. Данные о визите включают дату, материал/услугу, сумму и скидку. Развёртывание выполнено через Docker Compose: приложение и СУБД запускаются в отдельных контейнерах, а инициализация базы выполняется SQL-скриптами. Документация оформлена в формате Markdown и дополнена диаграммами, описывающими функциональную модель, потоки данных и структуру БД.


## Запуск
```bash
docker compose up -d --build
```
