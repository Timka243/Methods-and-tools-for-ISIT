# Система учёта визитов (Visit Tracking System)

**Ф.И.О. разработчика:** Валетов Тимур Маратович  
**Группа:** ДЭ-306  
**Тема проекта:** Учёт визитов по локациям с аналитикой  
**Цель проекта:** Веб-приложение для хранения и анализа визитов на базе PostgreSQL  
**Задачи проекта:** просмотр локаций/визитов/аналитики; добавление/редактирование/удаление визитов; запуск через Docker  
**Аннотация:** Flask + PostgreSQL, запуск через Docker Compose, учёт визитов и расчёт базовой аналитики.

## Запуск
```bash
docker compose up -d --build
